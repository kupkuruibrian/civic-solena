Project

Design and build the first phase of the Solena Civic website.

This is not a marketing website.

It is the digital headquarters of a new practice dedicated to designing how governments, institutions, public organizations and citizens experience one another through identity, communication, technology, environments and public systems.

The experience should immediately position Solena Civic as a category that does not yet exist.

Visitors should not feel like they discovered a branding agency.

They should feel like they discovered the people quietly designing the operating systems of modern civilization.

The emotional response should be:

These people understand public institutions differently.

Technical Direction

Build as a living environment rather than a webpage.

Use GSAP for architectural scroll choreography.

Use Motion for typography and interface state changes.

Use Anime.js for SVG network generation and line animations.

Use Lenis for smooth scrolling with weight and inertia.

Use WebGL shaders sparingly to blend the civic artwork into the page surface, creating the impression that the illustrations are embedded in the material rather than layered on top.

Represent the uploaded artwork as multiple depth layers. Extract contour paths, infrastructure lines, and node structures into SVGs that animate independently while maintaining perfect visual alignment with the underlying compositions. Typography should occasionally mask, reveal, or carve through these landscapes, reinforcing the idea that communication emerges from civic systems.

Performance is part of the design language. Every interaction should remain fluid at 60fps, with graceful degradation on lower-powered devices. Accessibility is non-negotiable: high contrast, semantic HTML, keyboard navigation, reduced-motion support, and readable typography are integral to the experience rather than afterthoughts.

The result should not resemble a landing page. It should feel like entering a quiet, living institution—one whose architecture is made of information, trust, and invisible systems. It should establish, from the very first scroll, the complete DNA of Solena Civic and leave visitors with the unmistakable sense that they have encountered a practice shaping the future of public institutions rather than simply designing for them.
